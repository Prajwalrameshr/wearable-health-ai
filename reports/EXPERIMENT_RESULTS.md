## Key Scientific Conclusions:
1. **Experiment 1 (Synthetic Baseline)**: Establishes ceiling clustering separation on clean synthetic data.
2. **Experiment 2 (Real Baseline)**: Measures real-world state discovery performance on authentic 6-feature core real Fitbit data.
3. **Experiment 3 (Synthetic -> Real Transfer)**: Direct zero-shot transfer of synthetic-trained GMM model onto held-out real test users.
4. **Experiment 4 (RQ3 Ratio Sweep)**: Controlled 1:1, 2:1, 4:1 synthetic augmentation comparison against Real-only baseline on identical held-out test users.
5. **Baseline Comparison**: GMM significantly outperforms Severity-Tercile (Sil 0.2168 vs 0.0313, p < 0.0001), proving multivariate structure is discovered beyond scalar severity score.
